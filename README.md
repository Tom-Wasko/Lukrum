# LUKRUM

Przeglądarkowa symulacja biznesowa dla szkół średnich: drużyny uczniów prowadzą kebaby na mapie Lublina,
a nauczyciel jako mistrz gry prowadzi rundy. Pomoc do lekcji WOS i podstaw przedsiębiorczości; projekt
na konkurs „Zwolnieni z Teorii”. Opis gry: [`gra/README.md`](gra/README.md).

## Uruchomienie

Windows: w folderze `gra/` kliknij dwa razy `start.bat` (macOS i Linux: `sh start.sh`). Za pierwszym razem skrypt
przygotuje środowisko, potem gra otworzy się pod adresem http://127.0.0.1:8765. Szczegóły: [`gra/README.md`](gra/README.md).

## Co gdzie jest

| Folder | Co |
|---|---|
| `gra/` | kod gry (Django + silnik w Pythonie), dane, testy, instrukcja dla graczy |
| `dokumentacja/` | stan prac, zadania, decyzje, wygląd, mapa, opisy funkcji, historia |
| `CLAUDE.md` | zasady pracy nad projektem |
